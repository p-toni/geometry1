Specter is an operator running missions with an agent under an explicit, versioned contract.

A proposed action does not execute until evidence has a place to land that can stop it. Approval is bound to the exact action it saw. If execution fails, that is a durable event — the mission holds until the plan is restated.

> [thesis|contact]
> Evidence that cannot change the decision is decoration.

The inspectable artifact is one frozen mission: proposal, evidence, approval boundary, failed execution. The live substrate is not public.
